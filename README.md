# Kalamitta

Mobiilipainotteinen PWA kalasaaliin pituuden arviointiin.

- Veneprofiilit: tallenna kaksi pysyvää mittapistettä ja niiden välimitta
- Mittaus mitta-asteikolla tai veneprofiilin pisteillä
- Saalislista, yhteispituus, jako ja tulostus/PDF
- Tiedot tallentuvat paikallisesti selaimeen

Mittatulos on suuntaa-antava. Viralliseen mittaan käytä mittalautaa tai mittanauhaa.
